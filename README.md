# Grok Second Brain (Karpathy LLM Wiki)

Приватная база знаний по методу Андрея Карпати.

## Структура

- `raw/` — сырые источники (только добавление, не редактировать). Сюда кладёшь статьи, заметки, транскрипты, PDF.
- `wiki/` — структурированная вики, которую ведёт LLM. Страницы концепций, сущностей, сравнений, индекс.
- `AGENTS.md` — правила и схема для LLM (как вести вики).

## Как работает

1. Кладёшь материалы в `raw/`.
2. Говоришь мне (или боту): «обработай новые источники».
3. Я читаю их, создаю/обновляю страницы в `wiki/`, ставлю ссылки, отмечаю противоречия.
4. Ты смотришь результат в Obsidian и задаёшь вопросы по готовой вики.

## Obsidian

Репозиторий можно подключить как Obsidian Vault (через Obsidian Git или клонирование).
