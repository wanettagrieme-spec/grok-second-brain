# AGENTS.md — Схема ведения LLM Wiki

Это правила для меня (Grok) и любых агентов, которые работают с этой базой знаний.

## Три слоя

1. **raw/** — неизменяемые источники. Читать можно, редактировать нельзя. Это истина.
2. **wiki/** — моя зона. Я создаю, обновляю и связываю страницы.
3. **AGENTS.md** — эти правила.

## Типы страниц в wiki/

- **entity** — человек, проект, инструмент, организация
- **concept** — идея, метод, принцип, модель
- **summary** — краткий пересказ одного источника
- **comparison** — сравнение двух и более вещей
- **analysis** — вывод по нескольким источникам

## Правила

- Каждая страница начинается с краткого вывода или сути.
- Всегда ставить обратные ссылки `[[название-страницы]]`.
- Отмечать противоречия, если источники расходятся.
- Не выдумывать. Если информации нет — писать честно.
- При добавлении нового источника обновлять связанные страницы, а не только создавать новую.
- Вести `wiki/index.md` как навигацию по всей вики.
- Периодически проверять на противоречия, сирот и устаревшие утверждения (health check).

## Формат страницы

```markdown
# Название

**Суть:** одно-два предложения.

## Основное
...

## Связи
- [[другая-страница]]

## Источники
- raw/...
```
